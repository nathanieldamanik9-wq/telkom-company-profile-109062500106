# Telkom University Company Profile - Praktikum

Project simulasi HTML, CSS, PHP native, MySQL/MariaDB, dan Git.
## Cara Menjalankan Project

1. Jalankan **Apache** dan **MySQL** melalui XAMPP Control Panel.
2. Letakkan folder project di `C:\xampp\htdocs\`.
3. Buka `http://localhost/phpmyadmin`, buat database sesuai nama di `config/database.php`, lalu import file `database/telkom_profile.sql`.
4. Sesuaikan koneksi database di `config/database.php` bila perlu (default XAMPP: user `root`, password kosong).
5. Buka `http://localhost/nama-folder-project/` di browser.
